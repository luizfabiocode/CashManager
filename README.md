# 💰 CashManager

> Aplicação desktop moderna, segura e offline para gerenciamento de finanças pessoais e controle de despesas.

## 🚀 Sobre o Projeto

O **CashManager** foi desenvolvido para oferecer uma experiência fluida, privada e rápida no controle financeiro do dia a dia. Como uma aplicação desktop, todos os dados são mantidos localmente na máquina do usuário, garantindo total privacidade e funcionamento offline.

---

## 🛠️ Tecnologias Utilizadas

Este projeto foi construído utilizando tecnologias modernas de desenvolvimento desktop e web:

* **[Electron](https://www.electronjs.org/)** - Framework para criação de aplicativos desktop multiplataforma usando tecnologias web.
* **[React](https://react.dev/)** - Biblioteca JavaScript para construção da interface de usuário.
* **[Tailwind CSS](https://tailwindcss.com/)** - Framework CSS utilitário para estilização rápida e moderna.
* **[SQLite](https://www.sqlite.org/)** - Banco de dados relacional leve e embutido para armazenamento local seguro.

---

## ✨ Principais Funcionalidades

* 📊 **Painel Financeiro**: Visualização clara de entradas, saídas e saldo atual.
* 🔒 **Armazenamento Local Seguro**: Seus dados financeiros salvos diretamente no seu computador sem dependência de servidores externos.
* ⚡ **Performance Nativa**: Aplicação leve, rápida e otimizada para o ecossistema Windows.
* 🖥️ **Interface Moderna**: Design limpo e responsivo focado na experiência do usuário.
